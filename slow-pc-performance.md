 Project 2: Resolving Slow PC Performance (High Memory Usage)
 Problem

User reported severe system slowdown, including delayed response times and application freezing. Issue persisted after restarting the computer.

🔍 Diagnosis

Restart did not resolve issue

Opened Task Manager to analyze system performance

Identified Google Chrome consuming ~85% of system memory

Multiple open tabs contributing to high RAM usage

 Resolution

Guided user to open Task Manager (Ctrl + Shift + Esc)

Instructed user to sort processes by memory usage

Advised closing unused Chrome tabs to reduce memory load

Performance improved immediately after reducing active tabs

 Outcome

System responsiveness restored

User able to resume work without lag or freezing

 Key Skills Demonstrated

Windows Task Manager analysis

Performance troubleshooting (RAM usage)

Application-level issue identification

User-friendly guidance and communication

What I Learned

This scenario highlighted how resource-heavy applications can impact system performance. It reinforced the importance of checking Task Manager early in the troubleshooting process and prioritizing simple, non-invasive fixes.
